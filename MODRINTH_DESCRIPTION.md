# EnchantPeak

**The ultimate enchantment reference for Minecraft — right inside REI/JEI.**

Search for any diamond or netherite item and instantly see all top-tier enchantment builds, organized by playstyle.

---

## Features

- 🔍 **Smart Search** — Find builds by item name, Chinese, pinyin, or enchantment name
  - `diamond sword` · `钻石剑` · `zuanshijian` · `Fortune` · `时运` · `shiyun`
- ⭐ **Searchable Entries** — Each enchantment build appears as a `★`-tagged entry in the REI item list
- 📖 **Information Tab** — Click any diamond/netherite item → press `R` → see builds in the **Information** tab
- 🗂️ **Build Variants** — Items with conflicting enchantments get separate builds (e.g. Pickaxe: Fortune build / Silk Touch build)
- ⚔️ **Full Coverage** — Tools, weapons, armor, and fishing rod
- 🌐 **Bilingual** — Chinese and English enchantment names in tooltips

## How to Use

**Method 1 — Search in REI:**
Type `★`, `钻石剑`, `zuanshijian`, or `Fortune` in the REI search box. Items tagged with `★` are EnchantPeak builds.

**Method 2 — Information Tab:**
Find any diamond/netherite item in REI → click it → press `R` → switch to the **Information** tab.
