# EnchantPeak 最强附魔 Mod

Minecraft Fabric Mod，MC 1.21.4，在 **JEI / REI** 中直接展示钻石与下界合金物品的**顶配附魔方案**。

## 功能

- 📖 以 **JEI** 和 **REI** 插件形式接入，无需独立界面
- 🔍 在 JEI/REI 中搜索任意钻石/下界合金物品，即可看到所有流派顶配方案
- ⚔️ 覆盖工具、武器、防具和钓鱼竿
- 🗂️ 按**用途流派**分组（如镐子：时运流 vs 精准流）
- 🌐 支持英文与简体中文

## 覆盖物品

| 类别 | 物品 |
|------|------|
| 工具 | 钻石/下界合金 镐子、斧子、铲子、锄头 |
| 武器 | 钻石/下界合金 剑、弓、弩、三叉戟 |
| 防具 | 钻石/下界合金 头盔、胸甲、护腿、靴子 |
| 特殊 | 钓鱼竿 |

## 构建

```bash
./gradlew build
```

输出 jar 位于 `build/libs/`。

## 依赖

- Minecraft 1.21.4
- Fabric Loader ≥ 0.16.9
- Fabric API
- JEI **或** REI（至少一个）
