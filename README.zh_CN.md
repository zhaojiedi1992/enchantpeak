# EnchantPeak — 最强附魔方案速查

> Minecraft Fabric Mod · MC 26.2 · 在 REI / JEI 中一键查看钻石与下界合金装备的顶配附魔方案

---

## 功能介绍

无需自己查 Wiki，打开 REI/JEI 搜索框，输入物品名即可看到该物品的**全部顶配附魔组合**，支持中文、拼音、英文搜索。

- 🔍 **直接搜索**：搜"钻石镐"、"zuanshijiangao"、"diamond pickaxe"都能找到
- ⭐ **附魔条目**：每个顶配方案作为独立条目出现在 REI 物品列表中，名称带 `★` 标记
- 📖 **Information 标签**：点击任意钻石/下界合金装备按 `R` 键，在 Information 页看到附魔方案说明
- 🗂️ **按用途分流**：同一物品分多个流派（如镐子：时运流 / 精准流；弓：无限流 / 修补流）
- ⚔️ **覆盖全面**：工具、武器、防具、特殊道具一网打尽
- 🌐 **中英双语**：物品名、附魔名均支持中文和英文搜索，内置拼音支持

## 安装与使用

### 依赖

| 依赖 | 版本要求 |
|------|---------|
| Minecraft | 26.2 |
| Fabric Loader | ≥ 0.19.3 |
| Fabric API | 0.157.0+26.2 或更新 |
| REI | ≥ 26.2.820（推荐）|
| JEI | ≥ 30.18.0.144（可选）|

> REI 和 JEI **至少安装一个**。两个都装也没问题。

### 安装步骤

1. 下载 `enchantpeak-x.x.x.jar`
2. 放入 `.minecraft/mods/` 目录（或 PrismLauncher 对应实例的 mods 文件夹）
3. 确保已安装 Fabric Loader、Fabric API 和 REI/JEI
4. 启动游戏，进入世界后在 REI/JEI 搜索框搜索即可

### 如何查看

**方式一：搜索列表直接找**
- 在 REI 搜索框输入 `钻石剑`、`★` 或 `时运`
- 带 `★` 的条目就是 EnchantPeak 的附魔方案条目

**方式二：点击物品查看 Information**
- 在 REI 找到任意钻石/下界合金装备
- 点击后按 `R` 键（查看使用方式）
- 切换到 **Information** 标签页，即可看到附魔方案说明

## 常见问题

**Q：搜索不到 ★ 条目？**
A：确保已进入世界（单人/多人均可），REI reload 完成后才会注册附魔条目。

**Q：只支持 REI 还是 JEI 也支持？**
A：两个都支持。REI 功能最完整（搜索列表 + Information + 自定义页面），JEI 提供自定义页面。

**Q：为什么没有石制/铁制装备？**
A：石制和铁制装备附魔价值有限，本 mod 专注钻石和下界合金（最终装备）。

**Q：支持模组附魔吗？**
A：目前只收录原版附魔。模组附魔支持在未来版本考虑中。
