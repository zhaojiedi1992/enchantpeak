# EnchantPeak

A Minecraft Fabric mod for MC 1.21.4 that shows the **best enchantment combinations** for diamond and netherite items directly inside JEI / REI.

## Features

- 📖 Integrates with **JEI** and **REI** as a plugin — no separate GUI needed
- 🔍 Search for any diamond/netherite item in JEI/REI and see all top-tier enchant builds
- ⚔️ Covers tools, weapons, armor and fishing rods
- 🗂️ Enchantments grouped by **build/playstyle** (e.g. Fortune build vs Silk Touch build for pickaxes)
- 🌐 Supports **English** and **Simplified Chinese** (zh_cn)

## Covered Items

| Category | Items |
|----------|-------|
| Tools | Diamond/Netherite Pickaxe, Axe, Shovel, Hoe |
| Weapons | Diamond/Netherite Sword, Bow, Crossbow, Trident |
| Armor | Diamond/Netherite Helmet, Chestplate, Leggings, Boots |
| Special | Fishing Rod |

## Builds per Item

| Item | Builds |
|------|--------|
| Pickaxe | Fortune build · Silk Touch build |
| Axe | Logging build · Combat build |
| Shovel | Fortune build · Silk Touch build |
| Hoe | Fortune build · Silk Touch build |
| Sword | All-in-one max build |
| Bow | Infinity build · Mending build |
| Crossbow | Piercing build · Multishot build |
| Trident | Loyalty build · Riptide build |
| Fishing Rod | Max build |
| Helmet | Standard build |
| Chestplate | Standard build |
| Leggings | Standard build |
| Boots | Standard build |

## Requirements

- Minecraft 1.21.4
- Fabric Loader ≥ 0.16.9
- Fabric API
- JEI **or** REI (at least one must be installed)

## Building

```bash
./gradlew build
```

The output jar will be in `build/libs/`.
